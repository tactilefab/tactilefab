# Contributing

Contributions are welcome — bug reports, braille corrections from readers and
transcribers, new language profiles, and code.

By submitting a contribution, you agree that it may be distributed under the
project's MIT License. Do not submit code you do not have the right to license
this way. Changes to the bundled liblouis library itself belong upstream at
[liblouis/liblouis](https://github.com/liblouis/liblouis).

Keep the tool dependency-free: plain HTML/CSS/JS, no build step. Braille
correctness issues are treated as release blockers — please include the input
text, the table used, expected braille and observed braille.
